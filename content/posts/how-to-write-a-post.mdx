## Starting a post

Create a file in `content/posts/`. The file name becomes the address, so `my-first-post.mdx` is published at `/posts/my-first-post`. Every post starts with its details:

```js title="content/posts/my-first-post.mdx"
export const meta = {
  title: "My first post",
  date: "2026-11-20",        // YYYY-MM-DD, used for ordering
  summary: "One or two sentences shown on the home page and in link previews.",
  draft: true,               // remove this line to publish
};
```

After that it's ordinary Markdown: `## Heading`, `**bold**`, `*italic*`, `[a link](https://example.com)`, lists, and so on.

## Code

Fenced code blocks are highlighted, in light and dark mode. Add a title after the language:

```python title="neuron.py"
import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def forward(x, w, b):
    """A single neuron: weighted sum, then activation."""
    return sigmoid(np.dot(w, x) + b)
```

Inline code like `np.dot(w, x)` gets a soft background.

## Maths

Write LaTeX between dollar signs for inline maths, like $\sigma(z) = \frac{1}{1 + e^{-z}}$, and between double dollar signs for a centred equation:

$$
\frac{\partial \mathcal{L}}{\partial w_{ij}^{(l)}} = \delta_j^{(l)} \, a_i^{(l-1)},
\qquad
\delta^{(l)} = \left( W^{(l+1)\top} \delta^{(l+1)} \right) \odot \sigma'\!\left(z^{(l)}\right)
$$

Equations are rendered when the site is built, so they load instantly and readers' browsers don't need any extra code.
